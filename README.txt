CAPTION FOTO HD — PETUNJUK SINGKAT
=====================================

Cara pakai
1. Ekstrak seluruh isi ZIP ke satu folder.
2. Buka index.html memakai Google Chrome atau Microsoft Edge.
3. Siapkan Excel dengan header "kalimat" di baris pertama. Gunakan template-kalimat.xlsx jika perlu.
4. Pilih file Excel/CSV di bagian Masukkan kalimat.
5. Pilih satu atau banyak foto. Jika foto lebih sedikit daripada kalimat, aplikasi akan mengulang foto sesuai pengaturan.
6. Geser teks langsung pada preview, atau gunakan slider kiri–kanan dan atas–bawah untuk posisi yang presisi.
7. Atur ukuran, lebar teks, outline, dan format hasil.
8. Klik "Generate & unduh ZIP". Semua foto HD akan tersimpan dalam satu ZIP.

Gaya font
- Preset Classic Bold memakai Arial Bold, teks putih, dan outline hitam yang disetel menyerupai contoh.
- Untuk hasil font yang benar-benar identik, klik "Ganti font" lalu unggah file font asli (.ttf, .otf, .woff, atau .woff2).

MODE VIDEO 9:16
================
1. Dari halaman utama, pilih tab "Video 9:16".
2. Unggah satu video MP4/WebM/MOV, atau tempel link TikTok lalu klik "Ambil video". Sumber tanpa watermark dipilih jika tersedia.
3. Masukkan satu quotes dan pilih tema, atau gunakan deteksi otomatis.
4. Pilih satu dari lima template susunan teks: Classic, Kolom besar, Kolom sedang, Minimal, atau Bold tengah (44 px, Black, posisi 50%/45%, lebar 72%, outline 7 px, jarak baris 1.16×).
5. Tarik teks pada preview untuk mengatur posisi. Atur ketebalan font 100–900, warna Putih/Kuning #E7C549, serta nyalakan atau matikan outline.
6. Klik "Simpan template" agar font, warna, ketebalan, ukuran, posisi, lebar, outline, dan jarak baris otomatis dipakai pada video berikutnya.
7. Aplikasi otomatis menyiapkan caption relevan sepanjang 1–3 kata, empat hashtag bertema, serta tiga request lagu IG/TikTok.
8. Pilih mode "IG/TikTok MP4" untuk realme 5 Pro/HP lama: 720 × 1280, 24 fps konstan, bitrate 2,8 Mbps, MP4 H.264 + AAC. Untuk HP baru/desktop tersedia Full HD 1080 × 1920, 30 fps.
9. Klik "Proses & unduh video". Setelah selesai, tekan "Bagikan MP4 ke IG/TikTok" agar file dikirim sebagai video melalui menu bagikan Android.
- Impor link TikTok memerlukan internet dan bergantung pada ketersediaan sumber TikTok. Gunakan hanya video milik sendiri atau yang sudah diizinkan pemiliknya.

MODE HP / PWA
=============
- Seluruh tampilan sudah responsif dengan tombol sentuh yang lebih besar.
- Pada HP, preview video otomatis berada tepat setelah bagian quotes agar mudah dilihat saat mengatur teks.
- Tombol cepat Preview, Ekspor, dan Bagikan tersedia tepat setelah panel ekspor pada Tipe 5 di HP.
- Pada HP, mode IG/TikTok MP4 aktif otomatis. Pengaturan ini dibuat khusus agar realme 5 Pro tidak kewalahan merender 1080p dan agar hasil memakai format sosial MP4 H.264 + AAC.
- Setelah video selesai, tombol "Bagikan / simpan ke galeri" muncul. Jika Web Share tidak didukung, aplikasi mengunduh file kembali.
- Aplikasi dapat dipasang ke layar utama sebagai PWA dan aset utama tersedia kembali saat offline.
- Android: buka lewat Chrome lalu pilih Pasang / Tambahkan ke layar utama.
- iPhone: buka lewat Safari, tekan Bagikan, lalu Tambahkan ke Layar Utama.
- PWA memerlukan hosting HTTP/HTTPS (HTTPS untuk penggunaan publik), bukan file://. Lihat CARA-PAKAI-DI-HP.txt.

MODE TEMPLATE TIPE 3
====================
1. Pilih tab "Tipe 3".
2. Unggah Excel/CSV untuk banyak quotes, atau masukkan satu quotes secara manual.
3. Template selalu menggunakan kanvas 4:5 berukuran 2160 × 2700, latar #38352F, teks putih reguler, dan tanda "- wordivee".
4. Hanya isi quotes yang berubah; posisi, font, warna, dan tanda dibuat tetap mengikuti referensi.
5. Klik "Generate & unduh ZIP" untuk mendapatkan semua gambar PNG HD.

MODE TEMPLATE TIPE 1 (BAGIAN 4)
================================
1. Pilih tab "Tipe 1".
2. Unggah Excel/CSV untuk banyak quotes, atau masukkan satu quotes secara manual.
3. Template menggunakan kanvas persegi 2160 × 2160, latar putih, quotes #1A1A1A rata kiri dengan blok teks di tengah vertikal, serta tanda "wordivee" di kiri bawah.
4. Hanya isi quotes yang berubah; layout, warna, font, dan tanda tetap mengikuti referensi.
5. Klik "Generate & unduh ZIP" untuk mendapatkan seluruh PNG HD.

Catatan
- Excel, foto, dan video yang diunggah diproses lokal di browser. Saat memakai link TikTok, tautan diproses melalui layanan pengambil video agar sumber bisa dimuat.
- Di HP, 100 foto tetap bisa diproses. Gunakan JPG dan tutup aplikasi lain; bila memori browser terbatas, bagi menjadi 25–50 foto per ZIP.
- JPG direkomendasikan untuk file lebih ringan. PNG menghasilkan ukuran ZIP yang jauh lebih besar.
- Jangan memindahkan index.html terpisah dari folder vendor dan template.


PERBAIKAN ANTI-LAG REALME 5 PRO
- Profil IG/TikTok MP4 memakai 720 × 1280, H.264 Baseline + AAC-LC, bitrate 2,8 Mbps, dan 24 fps konstan.
- Encoder menyusun setiap frame secara terkontrol; frame tidak dibuang ketika HP membutuhkan waktu lebih lama untuk merender.
- Realme 5 Pro dan perangkat Android otomatis diarahkan ke profil Anti-lag. Full HD 1080p30 tetap tersedia sebagai opsi.
- Hasil mode IG/TikTok selalu berekstensi .mp4 dan divalidasi memiliki container MP4 serta video H.264. File yang ternyata WebM tidak akan diberi ekstensi MP4 palsu.
- Jika mode IG/TikTok menampilkan "Encoder MP4 belum tersedia", perbarui Google Chrome dari Play Store lalu buka ulang aplikasi.

BAGIAN 5 — YOUTUBE DI LAYAR LAPTOP
============================================================
1. Buka tipe5.html dari tab Tipe 5.
2. Tempel link YouTube kartun, lalu tekan Tampilkan.
3. Pilih menit dan detik mulai. Durasi awal adalah 18 detik dan dapat diatur 5–60 detik.
4. Atur volume 0–100%. Nilai ini dipakai pada preview dan audio AAC hasil ekspor.
5. Ubah tulisan, posisi X/Y, ukuran, lebar teks, font Arial/Impact, dan pilih mode Datar atau 3D ikut layar. Teks juga bisa diseret langsung pada preview.
6. Tekan Simpan template untuk menyimpan pengaturan. Tekan Gunakan template untuk menerapkannya kembali kapan saja.
7. Tekan Preview untuk memeriksa, lalu Proses & unduh untuk MP4 Full HD 1080 x 1920.
8. Hasil memakai H.264 + AAC, 24 fps, dan bitrate video 8 Mbps.

Catatan: resolver YouTube membutuhkan internet dan dapat dibatasi oleh YouTube atau layanan publik. Gunakan hanya media berizin. Jika resolver gagal, pilih video yang sama dari Google Drive/HP. Panjang video harus minimal sama dengan durasi potongan yang dipilih.

UPDATE V16 — PIN SUDUT 3D MANUAL
- Buka Tipe 5, lalu tekan "Aktifkan 4 pin sudut".
- Seret pin 1 kiri atas, 2 kanan atas, 3 kanan bawah, dan 4 kiri bawah hingga garis mengikuti bezel layar.
- Pin dapat diedit meski resolver YouTube gagal; gunakan file video cadangan untuk preview/ekspor.
- Posisi disimpan otomatis di perangkat dan tidak terlihat pada MP4 hasil.
- Tombol Reset otomatis mengembalikan bentuk awal.
- Saat aplikasi dibuka langsung sebagai file lokal, YouTube dapat menolak iframe karena tidak ada origin; buka melalui server/PWA atau gunakan file cadangan.

UPDATE V19 — YOUTUBE DAN FILE LOKAL
- Foto laptop ditanam sebagai data internal yang aman untuk kanvas. Karena itu, membuka tipe5.html langsung dari folder/file lokal tidak lagi membuat kanvas ekspor tercemar.
- Perbaikan ini menuntaskan error "VideoFrames can't be created from tainted sources" yang masih bisa muncul pada V18 saat aplikasi dibuka lewat file://.
- Resolver YouTube diperluas menjadi 15 sumber publik dan dicoba paralel dalam tiga kelompok agar lebih cepat dan lebih tahan jika satu sumber mati.
- Jika semua sumber YouTube sedang dibatasi, panel file cadangan otomatis dibuka.
- Cache PWA dinaikkan ke V19.


UPDATE V20 — TEKS DATAR, FONT, TEMPLATE, DAN FOTO LAPTOP
- Tulisan dirender setelah video perspektif selesai, sehingga tulisan tetap datar dan tidak lagi ikut berubah bentuk 3D.
- Font dapat diganti dengan berkas TTF, OTF, WOFF, atau WOFF2.
- Foto latar laptop dapat diganti dengan JPG, PNG, atau WebP. Setelah mengganti foto, sesuaikan empat pin layar.
- Tombol Simpan template menyimpan posisi/ukuran teks, font khusus, foto laptop, dan posisi empat pin di perangkat ini untuk penggunaan berikutnya.
- Versi V20 tampil langsung pada panel YouTube dan memakai URL aset bercap versi agar cache V18/V19 tidak dipakai lagi.

UPDATE V21 — GOOGLE DRIVE DAN ALUR YOUTUBE TANPA JALAN BUNTU
- Panel sumber kini menyediakan YouTube, link Google Drive, dan pemilih file Google Drive/HP.
- YouTube memakai preview resmi youtube-nocookie dan tetap mencoba sumber ekspor otomatis. Jika dibatasi, panel Google Drive disorot dan aplikasi tidak lagi berhenti pada pesan error tanpa pilihan lanjutan.
- Link Google Drive mendukung format drive.google.com/file/d/.../view dan link unduhan Drive. File harus diatur ke “Siapa saja yang memiliki link”.
- Jika Google Drive memblokir pemutaran link karena izin/CORS, pilih file melalui tombol “Pilih dari Google Drive / HP”; di Android pemilih dokumen dapat membuka aplikasi Drive langsung.
- Sumber Drive dan file diuji agar minimal sepanjang durasi potongan sebelum tombol ekspor diaktifkan.
- Cache PWA dan seluruh URL aset dinaikkan ke V21.
- Ekspor tetap MP4 Full HD 1080 x 1920, teks tetap datar, dan fitur font/foto/template V20 tetap tersedia.


UPDATE V22 — DURASI, VOLUME, TEMPLATE, FONT, DAN TEKS 3D
- Durasi potongan sekarang default 18 detik dan dapat diatur 5–60 detik. Jumlah frame, rentang waktu mulai, preview, nama file, dan audio menyesuaikan otomatis.
- Volume dapat diatur 0–100%. Slider langsung mengubah suara preview dan sampel PCM diskalakan sebelum dienkode menjadi AAC.
- Dua font siap pakai tersedia: Arial Bold dan Impact. Unggah font TTF/OTF/WOFF/WOFF2 tetap tersedia.
- Mode tulisan dapat dipilih: Datar di atas komposisi atau 3D ikut perspektif layar laptop.
- Tombol Gunakan template menerapkan ulang template tersimpan. Template V22 juga menyimpan durasi, volume, font, mode tulisan, posisi/ukuran teks, foto laptop, dan empat pin layar.
- Tampilan HP memiliki kontrol sentuh penuh, susunan tombol template yang tidak sempit, pemilih Google Drive/HP, dock aksi, PWA, dan Screen Wake Lock saat ekspor jika didukung browser.
- Cache PWA dan seluruh URL aset dinaikkan ke V22. Setelah mengganti folder versi lama, hapus cache/PWA lama atau muat ulang paksa satu kali.


UPDATE V23 — PERBAIKAN LAG DAN GREEN SCREEN
- Jalur ekspor Tipe 5 sekarang memakai frame CPU-safe, bukan mengirim kanvas GPU langsung ke encoder. Ini mencegah bug frame hijau pada sejumlah Chrome/HP Android.
- Renderer menunggu proses WebGL benar-benar selesai sebelum setiap frame disalin.
- Frame sumber yang terdeteksi hampir seluruhnya hijau diganti otomatis dengan frame bersih terakhir sebelum dikomposisikan.
- Encoder mencoba mode software yang stabil terlebih dahulu, lalu kembali ke mode kompatibel perangkat bila software tidak tersedia.
- Keyframe dibuat setiap 1 detik dan encoder memakai latency realtime agar pemutaran hasil tidak tersendat beberapa detik.
- Setiap output tetap memiliki frame rate konstan 24 fps. Ekspor dapat berlangsung sedikit lebih lama karena setiap frame 1080 x 1920 diverifikasi lebih aman.
- Bila decoder sumber berhenti lebih dari setengah detik, aplikasi membatalkan file rusak dan meminta video sumber MP4 H.264, alih-alih mengunduh hasil yang membeku.
- Cache PWA dan URL aset dinaikkan ke V23. Ganti seluruh folder lama dan hapus cache/PWA V22 sebelum mencoba kembali.
